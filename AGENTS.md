# AGENTS.md

Guidance for coding agents (Codex and others) working in this repository.

Read `CLAUDE.md` at the repo root before making any change. It is the single source of truth for Asmita's safety principles, current feature state, commands, architecture and deployment, and it applies to every agent, not only Claude.

The application lives in `asmita/`. Run commands from there. `asmita/AGENTS.md` holds the Next.js version note: consult `asmita/node_modules/next/dist/docs/` before writing framework-touching code.
